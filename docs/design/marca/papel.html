Porque o denominador é um quadrático irredutível. Em A/(x − 1), o resto é constante porque o divisor tem grau 1; já um divisor de grau 2 deixa um resto de grau 1.

x² + 3(x − 1)(x² + 1) = Ax − 1 + Bx + Cx² + 1

O termo Bx + C cobre todos os restos possíveis. Se B = 0, ele se reduz ao caso constante; por isso o formato geral é o do primeiro grau.
